# OKM Pro Plus

This is the repository for the OKM Pro Plus project.

## ERP-Lite Tasarım Dokümantasyonu

Fabrika üretim, depo, satış, sevkiyat, cari, personel ve mobil operasyon sistemi için hazırlanan tasarım ve teknik ön taslak dosyaları [`docs/`](./docs/) klasöründe yer alır.

## Canonical Design Source of Truth

Bootstrap promptu gereği mevcut aşamada production code, migration, API endpoint veya frontend/mobile implementation üretilmemektedir. Güncel DISCOVER → DESIGN çıktılarının canonical kaynağı [`design/`](./design/) klasörüdür.

Başlangıç noktaları:

- [`design/project-discovery-report.md`](./design/project-discovery-report.md)
- [`design/README.md`](./design/README.md)
- [`design/decision-log.md`](./design/decision-log.md)
- [`design/implementation-readiness.md`](./design/implementation-readiness.md)

Design Gate sonucu şu an `BLOCKED` durumundadır; açık kararlar çözüldükten sonra `factory-erp-architecture` skill'i kullanılmalıdır.

Eski tasarım ve sunum arşivi [`docs/`](./docs/) altında korunmaktadır. Bu arşiv; ekran envanteri, web/mobil UX, public ürün kataloğu, veritabanı ön taslağı, üretim-depo incelemesi, proje sunumu, konuşma metni ve mockup görsellerini içerir.

# OKM Pro Plus

This is the repository for the OKM Pro Plus project.

## ERP-Lite Tasarım Dokümantasyonu

Fabrika üretim, depo, satış, sevkiyat, cari, personel ve mobil operasyon sistemi için hazırlanan tasarım ve teknik ön taslak dosyaları [`docs/`](./docs/) klasöründe yer alır.

Başlangıç noktası: [`docs/README.md`](./docs/README.md)

Kapsam; ekran envanteri, web ve mobil UX, public ürün kataloğu, veritabanı/teknik mimari, üretim-depo detay incelemesi, proje yönetimi sunumu, konuşma metni, mockup görselleri ve yeniden kullanılabilir `factory-erp-design-workflow` becerisini içerir.

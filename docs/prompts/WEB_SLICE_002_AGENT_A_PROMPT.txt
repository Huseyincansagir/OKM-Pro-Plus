Toggle değişimi yalnızca viewMode değerini günceller.
Toggle, quantity alanlarında veya operationPackagingId üzerinde mutation yapamaz.

Önerilen tip sözleşmesi:

```ts
type QuantityViewMode = "base" | "transaction" | "packaging";

type QuantityViewToggleProps = {
  viewMode: QuantityViewMode;
  onViewModeChange: (mode: QuantityViewMode) => void;
  operationPackagingId?: string | null;
  disabled?: boolean;
};
```

Repository’de mevcut domain tipleri varsa onları kullan; yeni tipler mevcut domain modeliyle çelişmemelidir.
`onViewModeChange` callback’i yalnızca yeni viewMode değerini almalı ve operationPackagingId veya quantity alanlarını değiştirmemelidir.
